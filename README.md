# Drift Signal 3D: The Long Quiet

A 3D, tabletop-style RPG remake of *Drift Signal: The Long Quiet* for the TSA Video Game Design event.
Walk nine rooms across three chapters, roll d20 skill checks, travel with companions, and solve nine puzzles. No combat, no audio.

Play: https://school-user.github.io/tsa-saga-3d/

Run locally: `python3 -m http.server 8000`, then open http://localhost:8000/. Tests and file guide: [docs/notes.md](docs/notes.md).
Three.js is vendored in `lib/` under the MIT license (`lib/THREE-LICENSE`).
